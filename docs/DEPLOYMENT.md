# Deployment

## Environment variables

Every variable read by `backend/app/config.py`:

| Variable | Default | Purpose |
|---|---|---|
| `LLM_PROVIDER` | `local_synth` | Provider name; one of `gemini`, `openai-compat`, `local_synth`, `echo`. |
| `GEMINI_API_KEY` | empty | Enables the Gemini provider when set. |
| `GEMINI_MODEL` | `gemini-2.0-flash` | Gemini model name. |
| `OPENAI_API_KEY` | empty | Enables the OpenAI-compatible provider when set. |
| `OPENAI_BASE_URL` | `https://api.openai.com/v1` | OpenAI-compatible endpoint. |
| `OPENAI_MODEL` | `gpt-4o-mini` | OpenAI-compatible model name. |
| `AQI_API_KEY` | empty | Enables live AQI. The adapter calls `/data/2.5/air_pollution`, maps the provider's 1-5 `main.aqi` index to a CPCB band, reports the band midpoint as `value`, and keeps the raw index in `native_index`. When empty, `GET /air` reports `source: not_configured` and the user-entered band is authoritative; when set but the provider fails, it reports `source: offline` and falls back to the saved band. |
| `STORE_BACKEND` | `sqlite` | `sqlite` or `memory`. |
| `DATABASE_URL` | `sqlite:///./data/air.db` | SQLite location. |
| `AUTH_SECRET` | per-boot random | HMAC token secret; set explicitly in production. |
| `FRONTEND_ORIGIN` | `http://localhost:8000` | CORS origin. |
| `ALLOWED_ORIGINS` | `FRONTEND_ORIGIN` | Comma-separated CORS allowlist. |
| `RATE_LIMIT_PER_MIN` | `200` | Per-client request budget per 60 seconds; `/health` is exempt. |
| `MAX_RATE_BUCKETS` | `10000` | LRU bucket bound. |
| `TRUST_PROXY` | `false` | Trust `X-Forwarded-For` for rate-limit bucketing, keyed on the proxy-appended rightmost hop; enable only behind a trusted proxy. |
| `TRUSTED_PROXY_HOPS` | `1` | Number of trusted proxy-appended hops to peel from the right of `X-Forwarded-For`; ignore caller-supplied leftmost entries. |
| `MAX_UPLOAD_BYTES` | `5242880` | Upload cap in bytes (5 MiB); one upload is parsed at a time. |
| `MAX_DOCUMENTS` | `10` | Documents per owner. |
| `PORT` | `8000` | Uvicorn port. |
| `LOG_LEVEL` | `info` | Log level. |

Remote LLM providers call their HTTP APIs with the standard library, so no
vendor SDK packages are required. A timeout, HTTP error, redirect, oversized
response or malformed response falls back to `local_synth`, and `/ask` still
returns a cited answer.

Uploaded PDF text is capped at 50,000 characters after sanitization
(`MAX_DOCUMENT_CHARS`); longer extracted text returns 422 rather than being
silently truncated. PDFs over 20 pages, or extraction that exceeds the
4-second in-process budget, the 6-second hard worker-process timeout or the
1 MB decompressed-stream cap, return 422 instead of consuming unbounded worker
resources.

Uploads are also bounded by a process-wide single-flight slot: only one PDF is
read and parsed at a time, and a concurrent upload gets a 503 with
`Retry-After: 2` instead of queueing. The 5 MiB default cap plus serialized
parsing keeps peak memory inside the 512 MB Render free instance, where each
spawned extraction worker can add hundreds of MiB.

## Render

The repository blueprint is `render.yaml`: a free web service running the
Docker image, with `AUTH_SECRET` generated by Render, `AQI_API_KEY` left
optional, and `TRUST_PROXY=true` because Render fronts the service.

The image starts Uvicorn with `--no-proxy-headers`, so Uvicorn never rewrites
`scope["client"]` from `X-Forwarded-For`; `TRUST_PROXY` is the single switch
that decides whether the application trusts the header for rate-limit
bucketing. Keep `--no-proxy-headers` on any other launch command as well, or a
spoofed `X-Forwarded-For` can bypass per-client limits even when
`TRUST_PROXY=false`.

The free instance has 512 MB of RAM. Keep `MAX_UPLOAD_BYTES` at 5 MiB: uploads
are parsed one at a time, because each spawned PDF worker can add hundreds of
MiB, and a burst of concurrent uploads would otherwise trigger an
out-of-memory restart.

With `TRUST_PROXY=true` the application ignores the caller-controlled leftmost
`X-Forwarded-For` entries and keys on the rightmost valid hop - the address
appended by the trusted edge proxy. `TRUSTED_PROXY_HOPS` (default `1`) selects
the Nth valid hop from the right, so raise it only when a known chain of
trusted proxies appends more than one entry. Empty and non-IP entries are
skipped; if no trusted hop remains, the direct peer address is used.

1. Push the branch and create a new Blueprint from `render.yaml`.
2. Render builds the Docker image and runs `uvicorn` on `$PORT`.
3. The blueprint generates `AUTH_SECRET`; set `AQI_API_KEY` only if live AQI is
   required. Keep `TRUST_PROXY=true` on Render so per-client rate limits use the
   forwarded client address.
4. Verify the deployment with
   `python scripts/smoke.py https://<your-render-url>`.

## Production hardening

- Set a strong `AUTH_SECRET`; the per-boot random secret is a development
  fallback only.
- Keep `AQI_API_KEY` empty for an offline-first deployment.
- Front the service with TLS; the security middleware already sends HSTS.
- Restrict `ALLOWED_ORIGINS` to the public origin in production.
- Set `TRUST_PROXY=true` only when a trusted proxy sets `X-Forwarded-For`.
  The limiter keys on the rightmost proxy-appended hop, never the
  caller-controlled leftmost entry; `TRUSTED_PROXY_HOPS` tunes the hop count.
  Leaving `TRUST_PROXY=false` elsewhere prevents header spoofing.
- Ordinary bodies are capped at 1 MiB and uploads at the configured
  `MAX_UPLOAD_BYTES` plus 1 MiB of multipart headroom (5 MiB by default).
  Uploads are serialized by a process-wide single-flight slot; concurrent
  uploads get 503 with `Retry-After: 2`, so a burst cannot exhaust the
  512 MB free instance.
- The free tier uses ephemeral storage, so SQLite data does not survive a
  restart.
